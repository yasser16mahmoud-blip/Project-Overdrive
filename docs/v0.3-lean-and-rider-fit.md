# Version 0.3: cornering lean and rider fit

## Bike lean

All three bike entities now expose a client-synchronized `overdrive:lean` property. The behavior script samples each bike's yaw change, scales the lean by movement speed, smooths it to avoid snapping, and updates the property only when it changes enough to matter. The resource-pack animation rolls the frame and turns the handlebars in response. Lean returns smoothly toward neutral when the bike straightens or slows.

## Rider fit

The rideable seat is lowered and moved slightly forward on all bike variants to bring the default mounted player pose closer to the seat/tank and reduce the floating appearance. No global player animation override is installed: replacing the vanilla player animation controller can conflict with skins, other add-ons, and the normal player animation stack. Consequently the rider uses Minecraft's native riding pose; a custom independently leaning arm/torso pose is not claimed in this version.

## Test in Bedrock

1. Import updated packs together; replace older installed versions if the launcher keeps a cached pack.
2. Check Content Log for entity property, Molang, and animation warnings.
3. Summon each bike and ride at low and moderate speed; steer left/right and verify a smooth opposite lean response.
4. Release steering and verify the bike returns upright without jitter. Check that the seat sits acceptably with the default player skin.
5. Test multiplayer and confirm lean updates are visible to other clients.

Animation/property sync behavior and rider seat appearance need validation in the target Bedrock version; Minecraft is not available in this tool environment for a live test.
